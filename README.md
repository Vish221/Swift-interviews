# Swift Interview Master

A searchable, interactive study guide for Swift and iOS interview preparation. This repository contains a static HTML app with curated interview questions, model answers, STAR framing, and likely follow-up prompts for speaking rounds.

## What is included

- 107 curated Swift/iOS interview questions
- 16 topics covering fundamentals, optionals, UIKit, ARC, networking, concurrency, and more
- Search and filter to quickly find a topic or concept
- Expand/collapse all sections for faster review
- "60-second answer" guidance for interview speaking practice
- STAR-style answer structure for behavioral framing
- Follow-up question prompts for deeper discussion
- Save / revised tracking and interview mode for active study

## Project files

- `index.html` — the complete interactive study guide
- `README.md` — project overview and usage notes

## How to use it

1. Clone the repository.
2. Open `index.html` directly in a browser, or serve the folder locally.
3. Use the search box to find topics quickly.
4. Open a question, review the answer, and practice the interview-style panels.

### Local preview with Python

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- The content is designed for interview practice and quick revision.
