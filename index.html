What is the difference between frame and bounds in Swift/UIKit?

Answer

frame describes a view’s rectangle in its superview’s coordinate system. bounds describes the view’s rectangle in its own coordinate system.

🎤 How to say it in the interview

“The main difference is in their purpose and behavior. frame describes a view’s rectangle in its superview’s coordinate system. bounds describes the view’s rectangle in its own coordinate system.”

★ STAR-style answer structure

Situation: I was comparing two coordinate systems in UIKit.
Task: I needed to explain the difference clearly.
Action: I described how frame is in the parent, while bounds is local.
Result: The interviewer understood when to use each one.

  • When would you choose this in a real iOS project?

What is the difference between a class and a struct?

Answer

A struct is a value type; assigning or passing it creates an independent value. A class is a reference type and multiple variables can refer to the same instance.

🎤 How to say it in the interview

“A struct is a value type, while a class is a reference type. This means Swift copies a struct when passed around, while a class shares the same object reference.”

★ STAR-style answer structure

Situation: I had to choose between modeling a value or shared state.
Task: I needed to explain the trade-offs clearly.
Action: I compared value semantics with reference semantics and discussed when each is appropriate.
Result: The design was easier to reason about and safer for app state.

↗ Likely follow-up questions
  • When would you prefer a struct?
  • What about inheritance?
  • How do ARC and reference counting fit in?

What are optionals in Swift?

Answer

Optionals represent either a value or no value. They force explicit handling of absence and help prevent nil-related crashes in Swift code.

🎤 How to say it in the interview

“Optionals are a core Swift feature. They let us model the idea that some values may be missing, which makes the code safer and forces us to handle nil explicitly.”

★ STAR-style answer structure

Situation: I was handling API response data that was not always present.
Task: I needed a safe way to model missing values.
Action: I used optionals and optional binding to unwrap safely before using the value.
Result: The app handled empty states without crashing.

  • Why is force unwrapping risky?
  • When do you use nil coalescing?
